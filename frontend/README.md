JobPrep AI — Frontend (Next.js + Tailwind)

## Getting Started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Key routes added:

- `/dashboard`
- `/upload`
- `/questions`
- `/practice`
- `/applications`

Backend setup (FastAPI) lives in `../backend`.
